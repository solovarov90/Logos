# Technomage

База знаний "Technomage" — это Obsidian-волт, описывающий реальность как информационно-энергетическую систему через IT-метафоры. Стиль: **кибер-мистика** (IT-директор говорит с Нео).

## Vault

## Tone of Voice

Подробные правила стиля: [tone-of-voice.md](references/tone-of-voice.md). Краткая суть:

- **ДА:** код, рендер, баг, фича, алгоритм, сервер, GPU, Wi-Fi, commit, root-доступ
- **НЕТ:** "вибрации", "вселенная любит тебя", эзотерическая вода, расплывчатость
- Каждый духовный процесс = IT-процесс (см. маппинг в references)

## Workflows

### 1. Написание поста по блюпринту

1. Прочитать блюпринт из `02_ТОП Посты/<название>.md`
2. Из блюпринта извлечь: Смысловое Ядро, Ключевые метафоры, Структуру блоков, Тональность
3. Подгрузить связанные концепты из `03_Концепты/` (по wiki-ссылкам `[[Concept]]`)
4. Написать пост строго по структуре блюпринта, соблюдая Tone of Voice
5. Добавить CTA (Call to Action) если есть в блюпринте

### 2. Создание нового концепта

Сохранять в `01_Инбокс/<Название>.md`. Формат файла:

```markdown
# <Название>: <IT-Метафора> (<Англ. термин>)

**Теги:** #тег1 #тег2
**Связи:** [[Концепт1]], [[Концепт2]], [[Концепт3]]

---

### Техническая суть (<IT-термин>)
Объяснение через IT-метафору.

### <Контекстный раздел>
Связь с другими концептами через wiki-ссылки.

### <Практический раздел>
Как это проявляется в жизни / как применять.

> "Цитата (финальная мысль)"
```

Правила:
- Заголовок ВСЕГДА содержит IT-метафору: `Магия: Инженерия Вероятностей`, `Хаос: Пространство вариантов (Raw Data)`
- Минимум 3 wiki-ссылки на существующие концепты
- Прочитать `03_Концепты/` чтобы найти связи

### 3. Ведение журнала (из Telegram)

Журнал пишется **сразу в `04_Журнал/`** (не в Инбокс). Файл = `04_Журнал/<DD.MM>.md`.

#### Первая запись за день — создать файл:

```markdown
# <DD.MM.YYYY>

---

### <HH:MM>
<Текст пользователя — оформленный, но без искажения смысла>

**🤖:** <Краткий комментарий бота: что заметил, паттерн, связь с концептами, поддержка>
Связано: [[Концепт1]], [[Концепт2]]
```

#### Повторная запись за день — дописать в конец файла:

```markdown

---

### <HH:MM>
<Текст>

**🤖:** <Комментарий>
Связано: [[Концепт1]]
```

#### Последняя запись / конец дня — добавить итоговый блок:

Когда пользователь явно просит итог дня, или если это последнее сообщение вечером — дописать в конец:

```markdown

---

## 📊 Итоги дня

**Режим:** 🟢 Наблюдатель / 🟡 Переключение / 🔴 NPC
**Энергия:** <1-10>

### Практики
- [x/  ] Благодарности
- [x/  ] Перехват внимания (<N> раз)
- [x/  ] Сброс важности
- [x/  ] Вечерний обзор

### Паттерны дня
<Краткий анализ: что сработало, что вытянуло в NPC, инсайты>

### Ключевые концепты дня
[[Концепт1]], [[Концепт2]], [[Концепт3]]

> "<Финальная мысль дня>"
```

### 4. Генерация нового блюпринта поста

1. Выбрать тему (из концепта, из журнала, или от пользователя)
2. Прочитать 2-3 существующих блюпринта из `02_ТОП Посты/` как образец структуры
3. Создать блюпринт в формате:
   - Статус, Цель, Связанные концепты
   - Смысловое Ядро (проблема → решение → тезис)
   - Ключевые метафоры (обязательно IT)
   - Структура поста (блоки повествования)
   - Тональность (ссылка на Tone of Voice)
4. Сохранить в `01_Инбокс/<Название>.md`

### 5. Анализ графа знаний (Автоматизированный)
 
 По запросу "белые пятна" / "анализ графа" используй скрипт:
 `npx tsx skills/technomage/scripts/analyze-graph.ts`
 
 Это покажет:
 - Изолированные концепты (мало связей)
 - Пропущенные узлы (ссылки в никуда)
 
 ### 6. Поиск по базе (Deep Search)
 
 Есл нужно найти конкретный термин или цитату:
 `npx tsx skills/technomage/scripts/search-vault.ts "<запрос>"`
 
 ### 7. Анализ структуры (Structure Analysis)
 
 По запросу "структура" / "обзор базы":
 **ЗАПРЕЩЕНО** читать файлы вручную через `read_file` (слишком дорого).
 Используй скрипт:
 `npx tsx skills/technomage/scripts/analyze-structure.ts`
 
 ### 8. Анализ журнала (Journal Analysis / Stats)
 
 По запросу "прогресс" / "анализ журнала" / "статистика":
 **ЗАПРЕЩЕНО** читать все файлы журнала вручную.
 Используй скрипт:
 `npx tsx skills/technomage/scripts/analyze-journal.ts`
 
 Он вернет JSON со статистикой (Энергия, Режимы, Практики) по всем дням. Используй этот JSON для ответа.
 
 ### 9. Навигация (Map)
 
 Основной файл навигации: `00_Map.md`.
 Если его нет или он устарел, обнови его скриптом:
 `npx tsx skills/technomage/scripts/update-map.ts`
 Затем читай только `00_Map.md` для понимания, какие файлы существуют.
