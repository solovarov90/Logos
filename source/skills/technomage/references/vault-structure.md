## Папки

### `01_Инбокс/`
**Все новые заметки создаются сюда.** Пользователь сам сортирует их в нужные папки.

### `02_ТОП Посты/`
Блюпринты (инструкции) для постов Telegram-канала. Два формата:

**Формат 1 — Развёрнутый блюпринт (основной):**
```
# Название: Blueprint
**Статус:** #статус
**Цель:** ...
**Связанные концепты:** [[A]], [[B]], [[C]]
---
### 1. Смысловое Ядро (Core Message)
### 2. Ключевые метафоры
### 3. Структура поста (блоки повествования)
### 4. Тональность (Tone of Voice)
```

**Формат 2 — Короткий пост (YAML frontmatter):**
```yaml
---
tags: [тег1, тег2]
date: YYYY-MM-DD
type: post
---
# Заголовок
Текст поста с [[wiki-ссылками]]
```

Ключевой файл: `00_Карта_Реальности.md` — архитектура всей системы (4 уровня: Hardware, Logic, Software, UI).

### `03_Концепты/`
Энциклопедия концептов. Каждый файл = один концепт.

Формат:
```
# Название: IT-метафора (Англ.)
**Теги:** #...
**Связи:** [[...]], [[...]]
---
### Техническая суть (IT-термин)
### Контекстные разделы
### Практика / Инструменты
> "Цитата"
```

Ядро системы (ключевые концепты, от которых расходятся связи):
- **Наблюдатель** — центральная роль (Admin Mode)
- **Внимание** — инструмент фиксации реальности (Write Head)
- **Эффект наблюдателя** — квантовая механика восприятия
- **Атман** — истинное "Я" (Root Admin)
- **Эго** — аватар (User.exe)
- **Карма** — закон причинности (Script)
- **Хаос / Порядок** — Data Lake vs SQL
- **Намерение** — вектор изменений (Intent)

### `04_Журнал/`
Ежедневные рефлексии. Имя файла = `DD.MM.md`.
Содержание: свободный текст → оформляется по шаблону из SKILL.md (Workflow 3).

## Wiki-ссылки

Все файлы связаны через `[[Имя Концепта]]`. Это ядро системы — граф знаний.
При создании нового контента всегда проверять существующие концепты и добавлять ссылки.
